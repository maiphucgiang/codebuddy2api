# WebUI 使用指南

[English](webui.md)

## 打开管理界面

源码运行时，先按 [README](../README.zh-CN.md) 配置网关，再从仓库根目录执行：

```bash
(cd web && vp install && vp build)
uv run --env-file .env converter.py --desensitize
```

Docker 构建会自动打包界面。访问 `http://127.0.0.1:8787/dashboard`，使用当前网关 API key 登录；未设置 key 时管理功能不可用。非本机访问请使用 HTTPS。

更换 key 后需重新登录，尚未完成的 OAuth 授权也需重新发起。

## 常用操作

- **运行概览**：查看请求、用量和凭证健康状态。官方账号余额可能包含其他客户端的使用。
- **凭证管理**：通过 OAuth 添加账号，或导入 `.info`、ZIP 文件。停用后不再用于新请求，凭证文件保留。导出文件含明文凭证，请勿分享。
- **模型路由**：设置模型启停、对外名称和指定账号；指定后不会回退到未选账号。
- **日志审计**：筛选请求、查看失败详情。清空明细会保留历史统计。
- **系统设置**：修改可编辑项；锁定项需在启动配置中修改，标记为重启生效的设置需手动重启服务。

**全部清空日志与统计不可撤销**，需输入弹窗中的确认文字并复核当前 API key；不会删除凭证或网关配置。

## 数据与备份

数据默认保存在 `auth/`，Docker 内为 `/data/auth`，可通过 `CODEBUDDY_AUTH_DIR` 指定其他目录。

请将整个数据目录挂载到可写的本地存储，不要让多个网关实例共用。

备份前先停止网关，再复制整个数据目录。目录包含凭证、设置和日志，请妥善保管。
